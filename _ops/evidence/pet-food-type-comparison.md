# 근거표 — pet-food-type-comparison

작성: 2026-10-21 (일일 작업). 영양 문서(판정 없음). 수록 기준(작성 전 고정): 원문(전문, 기관 게시 원문, 또는 저자 기관 저장소의 원 논문 초록)을 연 자료에서 위치를 찾을 수 있는 사실·수치만 본문에 싣는다. 뉴스·블로그·업체 글·위키, 다른 AI의 답은 근거로 쓰지 않는다. 건식·습식 비교는 수분·건물 기준·수분 시험 연구로, 생식 비교는 병원체 검출·기관 권고로 한정한다(효능 주장은 다루지 않음).

열람 환경 메모: WebFetch만 사용(셸 외부 다운로드는 프록시 403). pmc.ncbi.nlm.nih.gov는 reCAPTCHA로 열람 불가. doi.org 링크는 권한 요청 시간 초과.

## 검수 반영으로 지운·고친 문장
- 1차 검수: van Bree DOI(저장소에서 재확인 불가) 삭제 / "특히 생식을 먹은 직후에는" 한정(원문에 없음) 삭제 / 개 연구 활동량 군간 차 비유의(P=0.088) 추가.
- 2차 검수: 4절 도입 "'습식은 열량 밀도가 낮아 살이 덜 찐다'는 설명이 있다"(출처 없음) 삭제·재서술 / 6절 "같은 무게라도 수분이 많으면 열량이 낮다"(출처 없음) 삭제.
- 작성 중 자체 삭제: "냉동 생식은 수분으로 보면 습식에 가까울 수 있다", "집에 영유아·노인·면역 약한 사람이 있으면" (출처 없음).

- Nemser 2014 원 논문(PMC4152787) — reCAPTCHA로 미열람. FDA 설명(S6)으로만 인용.
- van Bree 2018 전문 — 미열람(초록만).

- 국내 시판 생식 병원체 조사 — 찾지 못함(본문 callout에 명시).
