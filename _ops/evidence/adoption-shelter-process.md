## 검수 경과

### 1차 독립 검수 (새 에이전트, 원고+참고 문헌만 전달)
- 불일치 0 / 출처에 없음 2 / 열람 불가 0, 과잉일반화 다수.
- 출처에 없음: ① 1절 제목 "보호시설에 들어오나"(출처는 발생 수) → 제목을 "유기동물은 한 해 얼마나 발생하나"로 수정. ② "개를 입양하면 동물등록 의무도 따른다" → 문장 삭제, 내부 링크 안내로만 남김.
- 과잉일반화: G1(구조견 사업) 조건(온라인 교육, 최대 10일, 중성화 원칙, 1마리)을 반려마루 일반 절차처럼 씀 → 표에서 빼고 "그 구조견 입양에 관한 안내"로 한정한 단락으로 분리. "한 사람이" 주어 삭제. description "공공 보호시설" 일반화 삭제. FAQ 1·3 범위 한정.

### 2차 독립 검수 (다른 새 에이전트, 원고+참고 문헌만 전달)
- 불일치 2 / 출처에 없음 0 / 열람 불가 0, 과잉일반화 2.
- 불일치 ① description·lead "두 시설 모두 … → 입양 후 관리": 서울은 후기 공유뿐 → "입양 후 관리" 부분 삭제, 두 지자체 입양 후 단계를 따로 적음.
- 불일치 ② 참고 문헌 N1 부제 오지정 → "유기동물 발생 현황 항목"으로 수정. S3에 최종 수정일 표기 추가.
- 과잉일반화: 경기 구조 동물 처치 문장 → "대규모로 구조해 반려마루로 옮긴 개들", "그 구조 사례에 관한 안내"로 한정. description에서는 삭제.
- 2차 후 남은 문장 없음(지적 문장은 모두 삭제 또는 범위 축소).
